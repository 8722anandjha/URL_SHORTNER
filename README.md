🔗 URL Shortener Application

A full-stack URL shortener that allows users to generate short and custom URLs with authentication-based access control. Server-side redirection is used for fast and reliable URL resolution.

🚀 Features
      -Create short URLs without login
      -Create custom URLs (logged-in users only)
      -View all created URLs (authenticated users)
      -Secure authentication using JWT and cookies
      -Server-side redirection
      
🛠️ Tech Stack

Frontend  
  -React
  -Redux Toolkit
  -React Router DOM
  -Tailwind CSS
Backend
  -Node.js
  -Express.js
  -MongoDB
  -Mongoose
Authentication
  -JWT
  -HTTP-only cookies
